# Something to Focus (Build v5.6.0)

## New in this build

- Added **PiP Focus mode** for corner-style focus controls.
- While Pomodoro / Countdown Timer / Stopwatch is running, you can open PiP and keep controls visible in a small window.
- If Document Picture-in-Picture is unavailable, app falls back to an in-app corner widget.
- Settings remain categorized: Appearance, Timer, Goals, Updates, Utilities.

## Features

- 9 themes
- Pomodoro + projects/tasks + weekly stats + daily goals
- Focus View (fullscreen)
- Utilities: Countdown Timer + Stopwatch
- PiP Focus mode (corner window)
- In-app EXE downloader

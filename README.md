# Something to Focus (Build v5.6.0)

## What changed in this build

- Added **PiP Focus Mode** for desktop app usage.
- You can now run Focus View in a small always-on-top corner window instead of full-screen.
- PiP works for:
  - Pomodoro focus sessions
  - Utility Countdown Timer
  - Utility Stopwatch
- Added PiP controls:
  - `PiP Focus` button in app header
  - `Exit PiP` button in Focus View

## Existing features

- Settings menu with categorized tabs
- 9 themes
- Pomodoro timer
- Projects + per-project tasks
- Weekly stats + daily goals
- Utility countdown timer + stopwatch
- In-app EXE downloader

## Stale build troubleshooting

1. Confirm badge shows **Build v5.6.0**.
2. In Settings > Updates, use **Reset Local Data** if needed.
3. Close old instances and launch newest exe from `dist/`.
